# P13 - UI/UX Polish

## Goal
Make the complete system coherent across supported inputs and screens.

### P13-T01 Small-phone layouts
Test smallest supported practical viewport, safe areas, touch collisions and text truncation.

### P13-T02 Tablet/desktop layouts
Use space intelligently; avoid merely scaling phone panels.

### P13-T03 Controller navigation
Focus order, back behavior, selected states and gameplay interaction parity.

### P13-T04 Accessibility
Contrast, icon+text critical states, non-color-only signals, reduced unnecessary motion where practical.

### P13-T05 Feedback/audio/effects
Repair stages, rewards, unlocks and errors each have consistent feedback hierarchy.

## UX audit
No surprise purchase prompt on spawn.
One modal at a time.
Core objective remains readable during gameplay.

## Definition of Done
A user can complete onboarding, jobs, upgrades and shop navigation on touch, mouse/keyboard and controller.
