# P16 - Release

## Goal
Move from feature-complete build to controlled public release.

### P16-T01 Full QA matrix
Solo/multi-client, new/returning/migrated profile, mobile/tablet/desktop/controller, reconnect, low-network conditions where testable.

### P16-T02 Data migration/recovery test
Backup/recovery reasoning, old profile fixture migration, load/save failure handling.

### P16-T03 Purchase checklist
All IDs correct, all sandbox scenarios passed, free path validated.

### P16-T04 Store metadata/assets
Experience name, description, icon, thumbnails, age/content declarations and discoverability metadata prepared consistently with actual game.

### P16-T05 Controlled public launch
Release in a limited/controlled manner before broad promotion.

### P16-T06 Monitoring/rollback readiness
Watch onboarding, save errors, job completion, economy anomalies, purchase grants and critical errors.

## Stop conditions
P0 data loss/duplication or broad value exploit blocks expansion.

## Definition of Done
Public users can enter a monitored stable build with rollback procedures understood.
