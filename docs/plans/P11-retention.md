# P11 - Retention

## Goal
Create reasons to return that reinforce core gameplay instead of replacing it.

### P11-T01 Daily jobs
Daily contract set generated/selected server-side with clear expiry semantics.

### P11-T02 Daily login reward
Modest reward track; missed days do not create punitive debt.

### P11-T03 Achievement framework
Data-driven condition/progress/reward definitions.

### P11-T04 Launch achievements
Cover first job, category milestones, company growth, co-op and long-term progress.

### P11-T05 Rotating contract hooks
Configurable featured contracts/events without hardwiring live calendar logic into job engine.

## Tests
Timezone/day rollover semantics, reconnect, duplicate daily claim, already-completed achievement migration.

## Definition of Done
Return systems are reliable, bounded and measurable through analytics.
