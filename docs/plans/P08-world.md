# P08 - World

## Goal
Deliver one coherent city with three progression districts and reusable job anchors.

### P08-T01 Residential
Tutorial/early game district, workshop access, readable routes.

### P08-T02 Downtown
Midgame mixed buildings and denser job variety.

### P08-T03 Industrial
Late-game large sites and co-op contract spaces.

### P08-T04 Job anchor/building system
Buildings expose tagged/configured interaction anchor sets rather than bespoke scripts per building.

### P08-T05 Navigation markers
World-space objective marker + distance; no minimap unless playtest evidence requires one.

### P08-T06 Performance/streaming pass
Measure client/server performance and enable streaming/LOD/content optimizations as needed.

## Content target
20-30 distinct building shells/locations can host multiple jobs.

## Definition of Done
All launch job categories have suitable world locations and navigation remains clear on mobile.
